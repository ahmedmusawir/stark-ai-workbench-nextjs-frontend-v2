## Lessons Learned

- Write a timestamp only after its event; anticipated times slipped in twice and were caught by checking `date` before packaging.
- Before a non-renewable live run, harden waits so selectors can't pass on the wrong element (e.g., sidebar titles containing the marker).
- An allowlist must come from server configuration, never from the request it judges. Run new regressions against the old code first to prove they catch the defect.
- Report layout: details up top; the last lines are Response file, Location, ZIP, Receipt, in that order.
- When launching a background server, record its process group from inside the launched shell (`setsid bash -c 'echo $$ > pidfile; exec …'`).
