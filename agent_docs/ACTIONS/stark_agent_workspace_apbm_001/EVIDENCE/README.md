# Reviewed inputs

These are versioned historical reports and selected sanitized contract evidence, not instructions to rerun discovery or old SQL scripts. PROVENANCE.json pins source archives. Historical FILE_INDEX files describe their source archive and may list files intentionally not copied here; the outer FILE_INDEX.json is authoritative for this issued pack. No digest-bearing private originals are included.

PREP contains the reviewed source recon; P0 records early unknowns (later target/session decisions supersede them); DISCOVERY captures advertised contracts and code anchors; LIVE captures observed behavior. Distinguish source claims from independently verified raw evidence. Current module RULINGS/DATA_CONTRACT override stale proposals such as durable-storage conclusions from old-session retention, six-file estimates, or the stateDelta recovery suggestion.
