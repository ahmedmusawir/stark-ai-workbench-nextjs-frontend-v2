# Frozen acceptance — APBM_000 v1.0
Architect-authored before engineering, 4 October 2026. Amend only through dated RULINGS_ADDENDUM entries. Every criterion below is mandatory for this module. Independent QA derives its test plan from this contract; Engineer self-checks are claims, not certification.

**Certification scope:** fixture-qualified workbench UI plus preserved production integration/source/build regression. Not live session correctness, cross-user authorization, endpoint switching, Supabase/RLS, Hermes isolation or shared deployment. Those remain phase 001 or release dependencies. A test of a presentation state is not proof that current production APIs classify it correctly.
