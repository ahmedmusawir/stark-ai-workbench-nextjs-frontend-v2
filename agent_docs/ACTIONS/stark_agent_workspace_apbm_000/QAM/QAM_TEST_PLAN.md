## 7. Limits, stops and retries

- No login, credentials, live agent/model, Supabase, GCS or cloud calls. Fixture traffic is loopback only. An unexpected external attempt or credential exposure → STOP, preserve evidence, report.
- STOP conditions: candidate/plan/rulings mismatch at Q2-0. Product source change during the run. Any request reaching a non-loopback origin. A need to edit product/maintained tests/config. A contract contradiction (one ruling question, then wait).
- Retries: an instrument failure gets one diagnostic retry, with the fix diff logged. A product assertion failure is never retried into green; it is preserved as a finding. Maximum 2 full browser runs (the second only after a logged instrument fix). Jest/tsc/build are run once (the build may be rerun once only for an environment failure, e.g. font egress).
- Wall-time bound proposed: ≤3h Q2 active execution. Environment blocker → one diagnostic, then report BLOCKED for the affected ACs and continue the rest.
