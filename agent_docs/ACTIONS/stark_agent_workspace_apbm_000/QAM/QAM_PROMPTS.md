# Seat procedures and handoff messages

## Q1 entry (Tony points independent Executor at QAM folder)
Read QAM_ENTRY and verify state/candidate. Perform Q1 only, fill preflight and independently draft test plan, export one indexed Q1 package to HANDOFFS and Downloads. State exactly what QA Lead must decide. Do not execute the complete Q2 board before approval.

## QA Lead intake
Read Q1 REVIEW_START_HERE, canonical AC/rulings, risk inputs, candidate identity, preflight, independent plan and controls. Resolve environment/contract gaps by owner; approve/amend actual plan and candidate. Supply an exact dated approval record, evidence policy, scope and run bounds. This packet did not preapprove those on your behalf.

## Q2 resume
Verify approved plan/rulings hashes and actual candidate equivalence; record Director release. Run authorized board autonomously, preserve failures and fix only disposable instruments within plan. Fill report/matrix and export Q2 package. A green Executor report requests Lead adjudication; it is not Gate Q.

## Failure/repair
Keep failure evidence immutable. QA Lead classifies. Executor may draft REPAIR_PROPOSAL only. Architect defines exact permitted change paths, mechanism, ACs and regression. Tony hands that ruling to Engineer; no concurrent Executor writes. Engineer repairs on the same QA line, returns facts; Tony commits. QA repins and follows Lead-approved affected/regression retest plan. Do not reset branch or overwrite attempt-001 with a greener run.

## Q5/final adjudication
With disposition authorizing cleanup, remove only declared disposable run-owned artifacts, preserve safe evidence, confirm product identity, update retained inventory and export Q5 package. QA Lead issues exact Gate Q and separate process verdict. Send one closeout package to Architect. Architect issues closeout, Engineer records, Tony performs Git. No automatic merge or deploy.

## Resumption/provider swap
Read state and its linked real records; name last completed checkpoint, actual candidate and next authorized action. Preserve valid work. Missing/contradictory approval means stop that step; no reliance on prior agent memory. The same person/model session may not masquerade as an independent reviewer of its own product work.
