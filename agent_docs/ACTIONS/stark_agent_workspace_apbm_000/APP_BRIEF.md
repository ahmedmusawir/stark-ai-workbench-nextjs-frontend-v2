# App brief — APBM_000 frozen scope

Give Tony and authorized internal lab users a familiar multi-agent workbench: choose an agent, open its workspace, start or revisit conversations, and inspect clearly marked demo context. Abacus informs organization; the current charcoal/zinc palette and Inter remain. The larger destination is configurable ADK middleware reaching Cyberlorean agents over A2A/Hermes; generic frontend components must not assume the cloud Greeting Agent roster.

Build the three approved screens inside the existing authenticated Next.js app. Reuse the current ReactMarkdown/GFM/code renderer, chat services, Supabase sign-in, Zustand and installed primitives. Include accessible mobile/tablet navigation, scoped theme/portal styles, filtering, per-agent recents, rename/archive presentation and operation binding, new-draft navigation, copy/read-aloud treatment, and local-only instruction/sample-document interactions.

This module retains existing run/history/catalogue bindings and existing configuration. It does not upgrade their reliability or authorization to the eventual DATA_CONTRACT by assertion. All full failure/recovery states are implemented as typed presentation states and exercised with controlled fixtures; production maps only states the current service actually establishes. Unsupported distinctions are not fabricated and remain APBM_001 work.

Configuration presentation is generic. Existing agent IDs/app names/bundle mappings remain unchanged. Optional labels/descriptions/icons may be added with compatibility defaults. The five cloud agents in screenshots are fixture examples; they do not authorize switching the current Hermes-oriented roster or endpoint.

No backend picker, model selector, streaming rewrite, new agent creation UI, transcript deletion, edit/regenerate, real file ingestion, instruction publishing, GHL actions, GCS writes, database migration, auth redesign, cloud deployment or dependency upgrade.

The definition of complete engineering includes implementation, focused regression tests, executable Playwright UI coverage, results with inherited failures explained, and the self-contained factual QA return. Product certification belongs to independent QA and its Lead.
